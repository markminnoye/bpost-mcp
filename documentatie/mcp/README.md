# MCP

{% hint style="warning" %}
Alfaversie. Dit onderdeel kan nog veranderen.
{% endhint %}

Met MCP koppel je de dienst aan een AI-assistent (zoals Claude). De assistent kan dan je adressenlijst voorbereiden, controleren en naar bpost sturen.

Dit hoofdstuk wordt volledig herschreven. Het geeft nu een eerste overzicht.

## Adres

De officiële URL is **`/mcp`**, bijvoorbeeld `https://bpost.sonicrocket.app/mcp`. **`/api/mcp`** blijft werken als legacy-alias voor bestaande koppelingen.
