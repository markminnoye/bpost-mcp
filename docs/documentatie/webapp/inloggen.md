# Inloggen

{% hint style="warning" %}
Alfaversie. Dit onderdeel kan nog veranderen.
{% endhint %}

Je meldt je aan met een **Google-account**. Je hebt geen aparte registratie of wachtwoord voor deze dienst nodig.

## Stappen

1. Ga naar `https://bpost.sonicrocket.app/dashboard`. Ben je niet aangemeld, dan stuurt de dienst je naar de aanmeldpagina.
2. Kies je Google-account.
3. Je komt terecht op het dashboard (**Accountinstellingen**).

Bij je eerste aanmelding wordt automatisch een account voor je aangemaakt.

## Afmelden

Gebruik de knop **Afmelden** rechtsboven op het dashboard.

## Lukt het niet?

Krijg je de melding "Er is geen account gekoppeld aan je login", neem dan contact op met support. Dat gebeurt als je login niet aan een account gekoppeld kon worden.

Staat de dienst op een ander adres (bijvoorbeeld een testomgeving)? Vervang dan `https://bpost.sonicrocket.app` door dat adres.
