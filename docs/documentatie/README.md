# Welkom

bpost e-Masspost helpt je om adressenlijsten klaar te zetten, te controleren en naar bpost te sturen.

{% hint style="warning" %}
Alfaversie. De webapp en de MCP-koppeling worden nog gebouwd en kunnen veranderen. Werk bij bpost in **testmodus** tot alles goed werkt.
{% endhint %}

## Waar vind je wat?

| Onderdeel | Status | Waar |
|---|---|---|
| bpost-kennis voor je AI-assistent (skill) | Beschikbaar | [Bpost-skill](bpost-skill.md) |
| Inloggen en je organisatie instellen | Alfa | [Inloggen](webapp/inloggen.md), [Instellingen](webapp/instellingen.md) |
| Mailings aanmaken en opvolgen | Alfa | [Mailings](webapp/mailings.md) |
| Een adreslijst inlezen, koppelen en nakijken | Alfa | [Adreslijst nakijken](webapp/adreslijst-nakijken.md) |
| Regels waarop we je adreslijst nakijken | Alfa | [Formaatvalidatie](webapp/formaatvalidatie.md) |
| Werken via je AI-assistent (MCP) | Alfa, wordt volledig herschreven | [MCP](mcp/README.md) |

Het volledige bpost e-MassPost-protocol (bestandsformaten, flows, foutcodes) vind je in de groep **Naslag bpost**. De **Changelog** toont wat er veranderd is.

## Wat komt er nog?

De webapp krijgt nog de adrescontrole en het indienen bij bpost, Deposits, en mailings op een gedeelde drive van je organisatie. Zodra die bestaan, krijgen ze hier een eigen pagina.
