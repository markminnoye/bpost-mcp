# Function: sameButCase()

> **sameButCase**(`a`, `b`): `boolean`

Whether two texts differ only in capitals and spaces: bpost writes everything in capitals.

## Parameters

### a

`string`

One text.

### b

`string`

The other.

## Returns

`boolean`

True when they are the same apart from capitals.
