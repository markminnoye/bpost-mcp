# Function: findUnsupportedChars()

> **findUnsupportedChars**(`text`): `string`[]

Distinct characters in `text` that bpost does not accept, in order of appearance.

## Parameters

### text

`string`

Any string, before or after normalization.

## Returns

`string`[]

Unique unsupported characters. Empty when every character is safe.
