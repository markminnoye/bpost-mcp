## Vervolg (na 29/09)

Pad is gekozen: XML via FTP, correcties via Opti. Onderstaande AFT-upload is een optionele meting, geen productkeuze.

### A. XML verder

```bash
npm run generate:mailing-xml -- --limit 10
npm run generate:mailing-xml -- --opti --limit 10
npm run generate:mailing-xml -- --limit 100   # of 200; 2RS kan traag zijn
```

Daarna: parser voor Create-2RS (MID per SEQ) en Opti-2RS (`compCorrection`).

### B. Optioneel — AFT naast Opti meten

Zelfde 200 adressen, als iemand wil zien hoe het portaal-AFT verschilt van Opti:

1. AFT-upload: `docs/samples/contrapunt/testadressen-200-aft.xls`
2. XML: `npm run generate:mailing-xml -- --opti --file docs/samples/contrapunt/testadressen-200.xlsx`

MailingCreate geeft alleen een WARN zonder correctietekst. Opti geeft de correctie als **7001** / `compCorrection`.
